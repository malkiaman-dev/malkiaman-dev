## Featured projects

### Urine Hydration & Kidney Stone Risk Detection
An AI healthcare app that analyses a photo of a urine sample and estimates hydration status and kidney-stone risk. OpenCV extracts colour features, a scikit-learn model classifies them, and a FastAPI backend serves results to a React interface.

`React` · `FastAPI` · `OpenCV` · `scikit-learn` · `Tailwind CSS`

[![Live demo](https://img.shields.io/badge/Live_demo-000000?style=flat-square&logo=vercel&logoColor=white)](https://urine-hydration-stone-risk-detectio.vercel.app)
[![Source](https://img.shields.io/badge/Source-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/malkiaman-dev/Urine-Hydration-Stone-Risk-Detection-System)

### Crop Yield Prediction System
A Flask web app that predicts crop yield at province and district level across Pakistan from rainfall, temperature, pesticide use and planted area, with input validation, automated preprocessing and downloadable PDF reports.

`Python` · `Flask` · `scikit-learn` · `pandas` · `ReportLab`

[![Source](https://img.shields.io/badge/Source-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/malkiaman-dev/crop-yield-prediction)

### Email Automation Ecosystem
A suite of Python tools for high-volume outreach: a PyQt6 bulk sender with multi-account rotation and resumable campaigns, a bounce analyser that flags fully blocked batches, a bounce cleaner that separates real failures from out-of-office replies, and a Gmail inbox cleaner.

`Python` · `SMTP` · `IMAP` · `pandas` · `PyQt6`

[![Source](https://img.shields.io/badge/Source-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/malkiaman-dev/Email-Automation-System)

### Web Scraping Toolkit
Production scrapers for lead generation and market research, with duplicate prevention, real-time CSV saving and multi-source extraction: [Google Maps](https://github.com/malkiaman-dev/GoogleMapDataExtractor) · [Y Combinator leads](https://github.com/malkiaman-dev/Y-Combinator-Lead-Scraper) · [ACBAR jobs](https://github.com/malkiaman-dev/ACBAR-Jobs-Scraper-App) · [AFR property](https://github.com/malkiaman-dev/AFR.com_Property-Scraper) · [Website email extractor](https://github.com/malkiaman-dev/Websit_url_to_email)

`Python` · `Selenium` · `BeautifulSoup` · `Requests` · `FastAPI`
